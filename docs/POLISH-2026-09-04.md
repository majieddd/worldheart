# Polish pass, 2026-09-04

Owner brief: "the sword swing looks terrible, and the animation does not even
show when you're in 3rd person; you can't jump; the movement feels clunky and
weird with no head bobbing. Massively improve the game experience in all
aspects, fix any graphical artifacts or polygon issues, and make the
animations of the characters and mobs and their actual body/build really good,
detailed, but also polygon style."

This file is the tracked list for that request. Every row was measured on the
running game before it was written down, and every row is closed by a
measurement, not by a diff.

## Numbers to re-measure, not quote

Draw calls with five ally archetypes and 75 enemies in frame: 304 per frame,
696k triangles. A real run fields one commander plus wardens, so about a
third of that. Each soldier archetype costs about 27 instanced draws (times
two with the shadow pass) because every joint's part is its own InstancedMesh;
merging same-material parts on the same joint would halve it if it ever
matters. `WH.renderer.info` accumulates across `WH.step` calls while the pane
is hidden, so reset it and step one frame before reading.
