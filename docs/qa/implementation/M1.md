# M1: camera ownership and the Bulwark arm

Owner: Codex, feature/99-planets-camera. Based on M0 PR #10.

The elbow now points back below the wrist instead of projecting toward the
blade. Shorter tapered armor retains the existing kit and cyan/gunmetal identity.
The [five-pose comparison sheet](m1/pose-sheet.jpg) shows rest, anticipation,
strike, recovery and return. These are injected animation-progress fixtures;
they prove silhouette changes, not synchronized hit timing or human feel.
The existing strike clock is retained. Wider choreography and all-species
model/foliage work remain M4 tasks.

Manual zoom/pan interrupts a flight at its current pose. Automatic breach focus
is off by default and, when enabled, yields to possession, building and recent
input. Home and the heart camera button provide an explicit return action.
Possession owns its inputs exclusively. Look filtering and third-person zoom
use elapsed time. Separate persisted bob/shake settings respect reduced motion.
First-person shake no longer consumes the combat random stream.

Visual review found a second rendering defect: scrolling into first person
while paused could leave the commander's body instance buffers visible around
the eye. Camera/visibility updates now run during pause, and instance buffers
refresh without advancing combat. The possession HUD has a dark backing so
controls remain legible over bright terrain.

Reproduce with the optional browser runtime described in [M0](M0.md):
`node tools/camera-check.mjs`, `node tools/browser-regression.mjs`,
`node tools/capture-poses.mjs artifacts/m1-after`, then `node tools/pose-sheet.mjs`
when both before/after captures are present.

Remaining acceptance: owner continuous mouse-input feel, all commander poses
at every camera distance, extreme terrain introduced in M3, and combat
telegraph/active-frame agreement in M4. This change is implemented and has
automated evidence; it does not close the full visual-quality milestone.
