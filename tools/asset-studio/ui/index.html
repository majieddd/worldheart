What each stage does
Concept generates an identity hero, six separate views, palette and walk/strike sheet with installed Krea models. Existing models can produce exact camera references. Generated views are proposals: reject changed costume, mirrored sides or inconsistent anatomy before approval. Shape reconstructs the approved image with the selected local engine. Paint uses the original reference projection or locally generated Trellis.2 textures. Inspect seams and identity in either route. Motion preserves an imported rig or builds an editable biped draft. The fitted Vey route replays surface repair, semantic paint, retargeting, wrist/digit fitting and sole checks. Other anatomies need a fitted profile before claiming the same quality. Inspect every clip before approving polish. The local pipeline never sends your prompts or assets to a paid generation API.
Automatic reconstruction and rigging need visual review, especially fingers, antlers, backs and unusual anatomy. A successful job is a candidate, not proof of production quality.
