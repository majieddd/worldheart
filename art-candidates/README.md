# Saved art candidates

Hard Cel 1.0.0 is the owner's selected candidate for future Worldheart adoption.
It is preserved in `hard-cel-v1/`, tagged `art/hard-cel-v1` and available as
`hard-cel-v1.zip`. The archive is self-contained; no generator is needed to reopen
it. Extract the ZIP, serve its directory with a local HTTP server, then open
`hard-cel-v1/painted-lab.html?view=commander&compare=1`. The right pane is Hard Cel.
For example, `python -m http.server 8153` from the extracted parent directory.

The candidate includes the exact source, engine, loaders, models, pigment,
provenance and licenses from runtime `4fcee910ca6fb71771fa8b8ba54d9a5172281a58`.
Its manifest records the 16 rendering dependency hashes. Do not edit that folder.
Preserve raw bytes across checkouts as required by `.gitattributes`.

`hard-cel-study.json` records three unreviewed experiments in `hard-cel-lab.html`.
The original shader and scene remain available independently of the comparison.
Owner approval of this art candidate does not imply a production game migration,
rigging, animation or mobile performance acceptance.
