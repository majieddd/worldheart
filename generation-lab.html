What this experiment changes

Independent workers sample the same terrain functions at the same coordinates. Results return in their original order. Proven height bounds can avoid expensive clearance queries; uncertain cases still run the detailed checks. An exact connectivity test rejects unsuitable candidates earlier, while successful worlds still pass every existing check.

These are captures of the full game, not simplified preview meshes. Terrain, colors and navigation arrays are compared exactly. Water, stars and other animated effects can differ between screenshots.

Target: under 5 seconds for ordinary planets and under 10 for difficult cases. The target is not yet met. Desktop timings do not certify phone performance.

Open each world separately for an interactive inspection. Running both at once competes for CPU and GPU time, so do not use simultaneous tabs as a speed comparison.
